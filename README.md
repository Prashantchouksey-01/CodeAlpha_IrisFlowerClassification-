# CodeAlpha_IrisFlowerClassification-
Iris Flower Classification using Machine Learning with Python and Scikit-learn. This project predicts Iris flower species based on flower measurements
🌸 Iris Flower Classification

Project Overview

This project focuses on classifying Iris flowers into three different species using Machine Learning.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Dataset

The Iris dataset contains 150 flower samples belonging to three species:

- Setosa
- Versicolor
- Virginica

Machine Learning Algorithm

Decision Tree Classifier

Project Steps

1. Data Loading
2. Data Preprocessing
3. Data Visualization
4. Model Training
5. Model Testing
6. Accuracy Evaluation

Objective

To predict the species of Iris flowers based on their measurements.
